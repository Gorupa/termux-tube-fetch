Developer Corner

Architecture: The frontend (Cloudflare Pages) communicates with a local Node.js server inside Android's Termux shell via an encrypted cloudflared tunnel — no VPS, no open ports.

Zero-Storage Magic: yt-dlp -J dumps raw JSON metadata, surfacing direct googlevideo.com edge URLs. Your browser fetches media straight from YouTube's CDN — the phone node never writes a byte.
